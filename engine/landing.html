原理与隐私

HOW IT WORKS

⚙️ 两级抓取，先快后全

T1

基础统计 · 约 2 秒

一次请求拿到官方 photostats 全表：每张照片的航司、机型、注册号、浏览量、评论与 EP/PW/SC/PC 获奖标记。立刻可看排行与分类。

T2

深度抓取 · 后台渐进

逐张访问照片详情页（默认快速模式约 4–5 张/秒，可切回标准约 2 张/秒；遇到限流会自动降速），解锁机场、国家、拍摄/上传日期、相机镜头、备注与缩略图。可随时暂停/继续，失败自动重试并标明原因。

♻

本地缓存 · 增量更新

结果存在浏览器 localStorage。下次打开同一 ID 秒出缓存，只抓新增照片；也可一键全量重抓刷新浏览量。

🔒 你的数据不出浏览器

  • 🚫没有服务器。本页只是安装说明书；抓取与统计全部发生在你的浏览器里，直连 jetphotos.com，不经过任何第三方。
  • 👤无需登录。公开统计接口对所有人开放，不读取你的账号、Cookie 或任何隐私信息。
  • 💾缓存只存本地。localStorage 按摄影师 ID 隔离，清除浏览器数据即可完全删除。
  • 🐢礼貌抓取。内置限速、退避与重试，避免给 JetPhotos 造成压力；请仅用于个人统计欣赏。
  • 📖代码透明。引擎是单个可读的 JS 文件，无混淆、无埋点、无网络上报。

基础统计约 2 秒。深度抓取默认快速模式（约 4–5 张/秒，800 张约 3–4 分钟），进度条上可切回标准模式（约 2 张/秒）；后台渐进渲染——抓一张亮一张，随时可暂停，进度自动保存。内置 429/503 退避与自动降速重试；请不要同时开多个窗口抓同一个 ID。

常见四类原因：① 限流 / Cloudflare 拦截（429/503）——请求过快或触发风控，引擎会自动退避 20 秒、降低并发并重试最多 4 次；② 照片已删除（404）——摄影师删除或下架，重试也无法恢复；③ 页面无照片信息——页面返回成功但内容为空（仅会员可见或已撤下）；④ 请求超时——网络波动。点进度条上的「⚠ 失败详情」可查看每张照片的失败原因与原图链接：可恢复的失败一键重试，永久失败可放心忽略，不影响其余照片的统计。

官方统计总表只有航司/机型/注册号/浏览量/获奖，不含机场与日期。这些字段来自每张照片的详情页，需要点「开始深度抓取」后逐张补齐。抓过的照片会永久缓存，之后秒开。
