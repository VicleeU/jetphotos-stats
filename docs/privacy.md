# Privacy

- No server, no account and no telemetry.
- Photo list/detail requests run in the visitor's browser against `jetphotos.com`.
- Results are stored in `localStorage`, scoped by photographer ID. Clearing site data removes them.
- The project does not collect, upload or sync personal photographer data.
- Do not put personal photographer IDs, names, photo records, caches or private screenshots in this repository, issues, pull requests or public demos.
- Test with synthetic fixtures. Keep the built-in rate limits, backoff and retries; do not add scraping bypasses.
- The official JetPhotos logo is used only for identification; this project is unofficial and unaffiliated.

If you discover a privacy leak, stop publishing and remove the data before opening a public issue.
