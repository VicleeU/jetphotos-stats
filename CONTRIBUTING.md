# Contributing

This is an unofficial community tool. Contributions are welcome, but keep changes small and test them against the local build.

1. Fork or branch from `main`.
2. Run `python3 tools/build-dist.py` and test the landing page and dashboard locally.
3. Follow the checklist in `tools/qa/checklist.md`.
4. Do not add personal photographer data, caches, logs or credentials.
5. Keep the built-in rate limits and the non-affiliation disclaimer.
6. Open a pull request describing the change and the browser/theme scenarios tested.

For release steps see `RELEASE.md`. For development constraints see `AGENTS.md`.
